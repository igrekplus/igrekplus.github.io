# 高雄エビ釣り場（釣蝦場）調査まとめ

> 対象旅行：2026年6月26〜28日 高雄2泊3日（5名）
> 調査日：2026年5月26日
> 情報源：Claude（Web検索）＋ Gemini（Google Maps）
> 絞り込み条件：高雄車站からタクシー30分圏内・夜間営業・ビール＋代客料理あり

---

## 基礎知識

台湾独自の娯楽施設。室内の専用プールでタイエビ（泰国蝦）などを釣り、釣ったエビをその場でスタッフに焼いてもらって食べる。ビールを飲みながら釣る居酒屋的な使い方が定番で、2〜3時間ゆっくり過ごすのが一般的。

- 道具はレンタル込み（竿・えさ・バケツ）
- 代客料理：釣ったエビをスタッフに調理してもらう有料サービス（1斤あたり100元前後）
- ビール・食事は基本どの店でも注文可能（台湾式居酒屋スタイル）
- 予約不要が基本。ただし週末夜は竿待ちが発生する場合あり（20〜30分程度が目安）
- 待ち方：日本のような行列ではなく、飲みながら竿が空くのを待つスタイル

### 料金システム（2種類ある）

| 方式 | 内容 |
| --- | --- |
| 時間制 | 1時間ごとに課金。釣れなくても料金は固定。初心者・グループ向けで予算が読みやすい |
| 重量制（秤斤計価） | 釣ったエビの重さで支払い。最低重量が設定されていることも多い。上手い人ほどお得、初心者は割高になりがち |

### 費用感（5名・2〜3時間の目安）

| 内訳 | 1人あたり |
| --- | --- |
| エビ釣り代（時間制・2〜3時間） | 250〜450元 |
| ビール数本 | 150〜200元 |
| 代客料理（エビ塩焼き等） | 100〜200元 |
| 合計目安 | 500〜850元（約2,500〜4,300円） |

### 営業時間帯の目安

| 時間帯 | 雰囲気 |
| --- | --- |
| 19:00〜21:00 | 夜市や観光の後に夕食代わりで入店できる時間帯 |
| 21:00〜24:00 | 最も盛り上がる時間帯。ローカル客が多く雰囲気が出る |
| 24:00〜03:00 | 深夜帯。空いてくるが24時間店なら引き続き営業 |

台湾では深夜まで営業が当たり前の文化。「朝4時まで釣ってる」ケースも珍しくない。

### Geminiから提供されたグループ向けのコツ

竿は5名全員分借りなくてもよい。3本だけ借りて2名はビールを飲みながら熱炒をつまんで応援し、交代で回すと糸が絡まるストレスが減り、全員がエビ釣りと居酒屋の両方を楽しめる。

メディアでも取り上げられた超大型エンタメ複合釣り堀。エビ・魚に加えてウシガエル釣りの池もあり、カエルはその場で三杯・塩酥・糖醋・蒜頭湯などで調理してもらえる。熱炒（居酒屋料理）のクオリティが高く評判。週末は若者・家族連れで賑わう。代客料理費は1斤100元。

- 混雑時は隣の人と糸が絡まりやすい
- 週末は熱炒の席が満席になることもある
