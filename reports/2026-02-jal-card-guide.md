## 2. 決済仕様（公式ベース）

### 2-1. JAL Payチャージ仕様

| 仕様項目 | 仕様定義（2026年2月7日時点） | 運用上の扱い |
|---|---|---|
| JALカード→JAL Payチャージ積算 | 通常時は積算対象外。キャンペーン時に例外付与あり。 | 「常時1.0%」前提で設計しない。 |
| JAL PayマイルUP（Step） | Step5条件は「20回 / 5万円 / 5万円（現金・JALカードチャージ）」。 | 回数・金額・チャージを月次で分離管理する。 |
| 還元率上限（決済側） | JAL Pay決済単体は国内0.5%から最大1.8%、海外1.2%から最大2.0%。 | 「2.1%」は前提付き試算として扱う。 |
| Step上乗せ対象上限 | 日本円決済のStep上乗せ対象は月5万円まで（基本マイルは上限なし）。 | 上乗せ対象枠（5万円）を超える決済は別手段と比較する。 |

### 2-2. QUICPayとコード決済仕様

| 仕様項目 | 仕様定義（2026年2月7日時点） | 運用上の扱い |
|---|---|---|
| 基本還元率 | QUICPayとコード決済の基本積算率は共通（国内0.5%、海外1.2%）。 | 日常決済は使い勝手で選択する。 |
| Step-Up上乗せ | 条件達成で翌月に+0.6%上乗せ。 | 月20回達成のため、少額決済を計画的に配分する。 |
| 「合計2.1%」の前提 | 「チャージ1.0% + 決済1.1%」は前提付き。通常時はチャージ積算対象外。 | 常時値としては使わず、キャンペーン時の参考値として扱う。 |
| JAL PLAZA等での差分 | QRコード読み取り決済に追加ボーナス設定がある。タッチ決済やQR提示は対象外条件あり。 | 空港・機内は事前に対象決済方法を確認して選択する。 |
| キャンペーン対象条件 | Apple Pay/Google Pay設定を条件に含む施策がある。 | 条件対象の月はQUICPay/Smart Code/JAL Pay加盟店を優先する。 |
| 20回達成の実務性 | 公式の優劣規定はない。実務上は非接触タッチが回数管理しやすい。 | 回数達成用途はQUICPay中心で設計する。 |

## 3. 運用方針（家族カードなし前提）

- 主戦場は **JALカード特約店での直接決済**（ショッピングマイル2倍）
- 特約店外は **JAL Pay（Apple PayのMastercardタッチ / QUICPay+）** へ集約
- Suicaチャージは利便性目的で使い、マイル主戦場としては期待しすぎない
- 既にJALゴールド発行済みのため、カード切替検討は優先度を下げる

## 4. 実行戦術（本会員1枚運用）

### 4-1. 支払い優先順位

1. 特約店でJALカード決済（最優先）
2. 特約店外でJAL Pay決済（iPhone）
3. Suicaは移動利便性を優先（マイル効率は別管理）
4. 月末に「特約店比率」を点検して翌月修正

### 4-2. 実務ルール

1. ドラッグストア・日用品は特約店ブランドに寄せる（ウエルシア/マツキヨ/ココカラ等）
2. 外食は特約店のチェーン・多店舗ブランドを固定利用（ロイヤルホスト、博多華味鳥など）
3. ECは特約店のオンライン店舗を先に確認（大丸松坂屋オンライン、紀伊國屋ウェブストアなど）
4. 交通系出費は、特約店レンタカー/交通ブランドを優先

### 4-3. QUICPayとコード決済の使い分け

1. 日常（コンビニ・スーパー・自販機）はQUICPay中心で、月20回条件の達成を優先
2. 空港（JAL PLAZA）や機内など、QR読み取りのボーナスマイル設定がある場面はコード決済を優先
3. 特約店でJALカード2倍が強い場面は、JAL PayよりJALカード直接決済を優先

## 5. 中目黒 × みなとみらい運用

### 5-1. 平日導線

- 平日支払いは「職場近辺で使える特約店」から先に選ぶ
- 昼食・日用品・帰宅導線の3カテゴリだけでも特約店固定化する

### 5-2. 週次・月次ルーチン

1. 週次: 直近1週間で特約店外決済の理由を3件だけ確認
2. 月次: 利用明細を「特約店 / JAL Pay / その他」で分ける
3. 翌月: 特約店化できる固定支出を1項目だけ追加

## 8. カード比較（後段）

### 8-1. このガイドでの扱い

- 既にJALゴールド発行済みのため、比較は「運用補足」に限定
- 目先はカード変更よりも、特約店比率の改善を優先

### 8-2. 補足

- JAL PayのApple PayはMastercardタッチ/QUICPay+中心のため、iPhoneでJAL Payを使い倒す観点ではMastercard系が運用しやすい
- ただし、カード変更コストがあるため、まずは現行カードで運用改善してから判断
