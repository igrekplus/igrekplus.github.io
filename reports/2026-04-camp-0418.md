# 2026年4月18日 キャンプ場比較メモ

夫婦 + 友人2人の4人で、1サイト利用を前提に比較したキャンプ場調査メモです。

## 前提条件

- オートサイトであること
- 4人で利用可能であること
- 中目黒駅から90分程度で行けること
- 4人で1サイト利用できること
- テント1張 + タープ + 焚き火が成立すること
- 大量収容施設でないこと

## 補足条件

- サイト面積は50㎡以上あると望ましいが、必須ではない
- グルキャンは「別サイトに分かれる」より「4人で一緒」が望ましい
- 15区画以上でも即除外ではないが、密集感が強い施設は優先度を下げる
- 温泉・風呂は不要
- 景色、静かさ、設備のきれいさは総合評価対象
- 電源は不要
- ウッドデッキや屋根付き要素は、あれば加点

## 価格メモ

- 安さ重視で見ると `たてやま倶楽部`、`ゴールドマウンテンオートキャンプ場`、`トバイヌマ GRANDFIELD` は下限が低い
- 中価格帯は `バンブーグローブ オートキャンプ場` と `星海の香AutoCampHills`
- 人数課金型の `蜂花苑やどろぎ荘ミロクキャンプ場` と `ぼくらのミナノベース` は、4人になると総額が上がりやすい
- `北川空竜キャンプ場` は総額10,000円だが、面積22m²のため価格だけでは比較しにくい

## 総合判断で見たい観点

- 中目黒駅からの実感距離
- 4人で1サイト利用したときの余裕
- テント、タープ、焚き火の配置しやすさ
- サイト同士の密集感
- 景色の強さ
- 静かに過ごせそうか
- 設備の新しさ、清潔さ
- 雨天時の逃げ道があるか
