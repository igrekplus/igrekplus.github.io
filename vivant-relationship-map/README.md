# VIVANT(ヴィヴァン)人物相関図

TBS「日曜劇場」ドラマ「VIVANT(ヴィヴァン)」の人物相関図です。
画像生成ではなく HTML + SVG で描いているため、テキストを書き換えるだけで
人物の追加・関係性の修正・配置換えができます。TBS公式サイトの人物一覧を
ベースに、公式の相関図(VIVANT BOARD)よりも詳しい情報をまとめる方針で作っています。

`index.html` 単体で動作します。ビルド不要・外部ライブラリ不要のため、
ファイルをそのまま GitHub Pages に置けば表示されます。

## ファイル構成

```
vivant-relationship-map/
├── index.html            相関図 + 人物情報 + 確定/未確定まとめ(公開ページ本体)
├── VIVANT人物情報.md       一次情報。役名・関係性の根拠はここに書く
├── img/                   TBS公式サイトから取得した人物写真(トリミング済み)
└── README.md              このファイル
```

**編集の順番は必ず「まず MD → 次に index.html」です。** `VIVANT人物情報.md` が
一次情報で、`index.html` 内の `PEOPLE` / `RELATIONS` / `STATUS` はそこから
手で転記したデータです(自動連携はしていません)。MD だけ直して HTML を
直し忘れると、ページとMDの内容がずれるので注意してください。

## データソース

- **氏名・俳優名・写真**: [TBS公式サイト「登場人物」ページ](https://www.tbs.co.jp/VIVANT_tbs/chara/)。
  2026年版で活動している29名がここに掲載されています。
- **関係性・あらすじ**: 放送第11〜13話の内容を整理したものです(ユーザー提供の
  下調べ情報から、確度の低い記述・私見・出典タグを取り除いて MD に再構成しました)。
- **基準時点**: 2026年8月16日(日) 14:58。最新放送済みは第13話まで。
  第14話は同日21:00放送のため、この版には未反映です。

公式の「VIVANT BOARD」相関図は人物と一言メモだけのシンプルな構成ですが、
本ページはそれより詳しく、二重の所属・伏線・考察段階の情報まで含めて
整理することを目的にしています。

## ライブラリを使わなかった理由

| 候補 | 判断 |
| --- | --- |
| vis-network / Cytoscape.js | Canvas 描画のため、写真・役名・俳優名・説明文を積んだ「カード」表現ができません |
| React Flow | カード表現は最適だが React とビルド環境に依存し、単一 HTML で配信できる手軽さを失います |
| Mermaid | テキスト編集は簡単だが写真を入れられません |
| GoJS | 商用ライセンス |

ライブラリが本来提供する機能(自動レイアウト・矢印・境界での線停止・
ズーム・配置の永続化)は index.html 内に自前で実装しています。

## 編集方法

### 1. まず `VIVANT人物情報.md` を直す

新しい放送回の情報が出たら、まずこの MD に追記・修正してください。
章立て(二重構造の一覧 → 勢力 → 陣営別の人物 → 確定/未確定まとめ)は
そのまま index.html の構成と対応しています。

### 2. `index.html` の `PEOPLE` に反映する

```js
{
  id: "nogi", name: "乃木憂助", actor: "堺 雅人",
  faction: "shosha",                 // FACTIONS の id。背景ゾーンの色分けに使われる
  photo: "nogi.webp",                // img/ 内のファイル名。null なら頭文字表示
  officialPage: true,                // 2026年版TBS公式ページに掲載されているか
  documented: true,                  // このMD/ページで役割を裏取りできているか
  dual: { faction: "beppan", label: "裏: 別班" },  // 裏の所属(なければ省略)
  tag: "拉致された5人",               // 補足バッジ(任意、クリックで開く詳細に表示)
  tagline: "丸菱商事の商社員、その裏の顔は別班の工作員", // カードに最初から表示される一言
  bio: "...",                        // クリックすると開く詳しい説明文(カードと人物情報セクション)
  // x, y は省略可。書かなければ自動整列(力学的レイアウト)が配置する
}
```

`faction` を書くとカード左端・上端の色と背景ゾーンの色分けに反映されます
(かつては「所属線」を自動生成していましたが、線が密集して図が重く見える
一因だったため今は廃止し、背景ゾーン+カードのバッジで表現しています)。
`dual` を書くと「裏の所属」への線(secretカラーの太線、相手陣営の重心へ
向けて引かれる)も自動生成されます。

### 3. `RELATIONS` に人物間の関係を足す

```js
{ from: "nozaki", to: "beppan", kind: "hostile", dir: "to", unsure: true,
  label: "拉致事件の黒幕として浮上(動機不明)" }
```

- `kind`: `trust`(信頼・協力) / `hostile`(敵対・追及) / `watch`(監視・追跡) / `bond`(因縁・血縁) / `secret`(正体・伏線)
- `dir`: `to`(片方向) / `both`(相互) / `none`(向きなし)
- `label` は from→to 方向、`back` を足すと to→from 方向の説明も書けます(例: 「指令」⇄「従う」)
- `unsure: true` で破線 + 「?」表示になります。**確定していない情報は必ずこれを付けてください。**

### 4. `STATUS` に確定/未確定のまとめを足す

`STATUS.ok` / `STATUS.watch` / `STATUS.guess` の3配列にテキストを足すだけです。
ページ下部の「確定 / 未確定」セクションにそのまま反映されます。

### 5. 配置の保存

カードをドラッグして並べ替えたあと、ツールバーの **「座標を書き出す」** を押すと
`const SAVED_LAYOUT = [...]` の形で出力されます。`index.html` の同名の行と
丸ごと置き換えれば配置が固定されます。ドラッグ結果は localStorage にも
自動保存されるため、リロードしても消えません。

## 実装している機能

- **自動整列(力学的レイアウト)** — 関係線でつながった人物どうしがバネで引き合い、
  すべての人物が互いに反発する簡易な force-directed シミュレーションで配置を
  決めます。関係が強い人ほど自然に近づくため、扇形の固定リング方式だった頃より
  「関係の距離」が見た目の距離に近づきます。明示的な関係を持たない人物が散らば
  らないよう、陣営内へのごく弱い引力を補助的にかけています。座標を書かずに
  人物を追加でき、カード同士は重なりません(シミュレーション後に仕上げの押し出し
  処理を入れて保証)
- **陣営を背景ゾーンで表現** — 陣営そのものはカード化せず、メンバーのカード配置を
  囲む角丸の矩形を敷いて背景を色分けし、左上にラベルチップで陣営名を表示します。
  輪郭のはっきりした「オブジェクト」に見えるよう、あえて曲線的な凸包ではなく
  直線的な矩形にしています。カード側にも上端の色・アイコン風のドット+陣営名
  バッジを付けているので、位置だけに頼らず陣営が分かります(丸菱商事のように
  所属者が多い陣営でも、全員を陣営カードへつなぐ線が要らなくなり、図がすっきり
  しました)
- **陣営のホーム地点は格子状(3×2など)** — 円周上ではなく `Math.ceil(sqrt(陣営数))`
  列の格子に配置します。横に広いビューポートを無駄なく使え、対角の陣営どうしも
  近くなります
- **カードは写真と名前を大きく、詳しい説明はクリックで開閉** — 既定では大きな
  写真・名前・一言(`tagline`)だけを表示し、詳しい説明文(`bio`)とバッジは
  カードをクリックすると開きます(ドラッグと判定が競合しないよう、pointerdown
  からの移動量がしきい値以下の場合だけ「クリック」として扱っています)
- **裏の所属の可視化** — `dual` を書いた人物からは、裏の所属陣営(の重心)へ
  向けて太い線が自動で引かれます
- **矢印の向きと双方向ラベル** — 関係の方向を表現。相互関係は from→to / to→from
  それぞれに違うラベルを付けられます
- **関係線は緩い弧で描画** — 直線だと交差が集中して読みにくくなるため、線ごとに
  曲がる向き・強さをずらしています。同じ2人を結ぶ複数の線(相互関係+secret線など)
  も重ならないようにしています
- **カード境界での線の停止** — 線がカードの下をくぐらないよう、矩形との交点で止めています
- **ズーム / パン / 最大化** — ホイールで拡大縮小、背景ドラッグでスクロール、
  「最大化」ボタンでビューポートを画面いっぱいに広げられます
- **左右の余白なし** — ページ全体を `max-width` なしで画面幅いっぱいに広げています
- **配置の永続化と書き出し** — localStorage 保存 + コードへの貼り戻し
- **二重構造テーブル・人物情報カード・確定/未確定まとめ** — すべて `PEOPLE` /
  `RELATIONS` / `STATUS` から自動生成。テキストの二重管理箇所を減らしています
- **ライト / ダークテーマ** — 閲覧者の設定に追従します

## 写真について(重要)

`img/` 配下の画像は、大半が TBS公式サイト([https://www.tbs.co.jp/VIVANT_tbs/chara/](https://www.tbs.co.jp/VIVANT_tbs/chara/))
に掲載されている公式写真を取得したものです。以下の2名は2026年版の公式「登場人物」ページに
掲載がないため、別ソースから取得しています。

- ノゴーン・ベキ(役所広司): [リアルサウンド](https://realsound.jp/wp-content/uploads/2023/09/20230912-vivant-01.jpg) 掲載の劇中カット
- 山本巧(迫田孝也): Google画像検索経由で取得した公式ポスタービジュアル(TBSクレジット入り)

いずれも円形アイコン表示用に顔中心で正方形トリミング・240px にリサイズしたものです
(31名分、合計 約340KB)。

**著作権は放送局・制作サイドに帰属する画像です。** 2026年8月16日にユーザー了承のうえ
`igrekplus.github.io/vivant-relationship-map/` で公開済みです(トップページ等からリンクは
していない、個別URLでのみ到達可能な形)。著作権上の指摘があれば速やかに取り下げます。

- 乃木明美(高梨臨)のみ、適当な写真が見つかっていないため `photo: null`(頭文字表示)のままです。

## 動作確認

初回実装時は Playwright(Chromium)でライト/ダーク両テーマを開いて検証しました。その後の
更新(関係線を弧に変更/人物追加/最大化ボタン/力学的レイアウトへの作り替え/写真2枚追加/
カードの大型化とクリック開閉/背景ゾーンの矩形化/ページ全幅化)は Claude Code の
ブラウザプレビューで以下を確認しています。

- コンソールエラーが発生しないこと
- カード32枚(人物のみ。陣営は背景ゾーンで表現するためカード化していない)、関係線47本が描画されること
- **カードどうしが1箇所も重ならないこと**(力学的レイアウト+矩形どうしの押し出し処理で検証。
  縦長になったカードでは円による近似だと斜め方向の重なり判定に漏れが出たため、幅・高さの
  軸それぞれで矩形として判定するよう修正した)
- カードをクリックすると詳しい説明とバッジが開閉すること、展開中もカードどうしが重ならないこと
- ドラッグ・ホイールズーム・最大化・座標書き出しダイアログが動作すること
- ページの左右余白がほぼゼロで、画面幅の98%程度まで使われていること
- 人物情報セクション・二重構造テーブル・確定/未確定まとめが正しく生成されること

写真については、既存29枚は初回実装時の Playwright 検証で読み込みを確認済みです。追加した
ベキ・山本の2枚は、ブラウザプレビュー環境の制約で `<img>` 読み込みの直接確認ができな
かったため、代わりに Pillow でファイル自体の整合性(240×240 の正しい webp であること)を
確認しています。実機のブラウザで見た目に問題があれば教えてください。

検証スクリプトは実行時の一時ファイルのため、リポジトリには含めていません。
